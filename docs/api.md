# DMS API

| 方法 | 路径 | 权限/用途 |
| --- | --- | --- |
| POST | `/api/auth/login` | 用户登录 |
| GET | `/api/admin/dashboard` | 文档治理指标 |
| GET | `/api/admin/work-orders` | 受控文件列表 |
| GET | `/api/shopfloor/dashboard` | 协作者工作台 |
| POST | `/api/shopfloor/work-orders/{id}/reports` | 提交版本记录 |
| POST | `/api/admin/retention-decision` | 判断文档保留、保全、复核或处置 |
